# Банк кейсов STAR

Кейсы для поведенческих вопросов. Каждый ссылается на блок в `career-data/blocks/`: цифры и факты берутся оттуда, здесь только подача.

## 1. <Название кейса> → <block-id>

**S** — ситуация, одно-два предложения.
**T** — задача и твоя роль.
**A** — что сделал, подробно, по шагам.
**R** — результат с метрикой из `core.md`.

Под какие вопросы: <«расскажите о конфликте», «о провале», «о влиянии без полномочий»>
