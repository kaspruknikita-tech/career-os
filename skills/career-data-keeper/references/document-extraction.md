# Разбор документов

Документ — это заявка, не подтверждение. Всё извлечённое подтверждается пользователем до записи.

## По типам

| Документ | Что тянуть | Куда | Чему не верить |
|---|---|---|---|
| Перформанс-ревью | Цитаты руководителя, конкретные результаты, зоны роста | Результаты → блоки. Зоны роста → `gaps.md`, не в резюме | Внутренний жаргон и кодовые имена проектов — спрашивать, что это |
| Описание проекта, ТЗ, презентация | Контекст, скоуп, стек, роли | Черновик блока | Плановые цифры вместо фактических. «Планировали -30%» это не результат |
| Переписка, Slack, задачи | Реальные решения и их автор | Секция «Что сделал», калибровка роли | Обсуждение не равно внедрение. Искать подтверждение, что дошло до прода |
| Старое резюме | Роли, даты, тайтлы, стек | Проверка `core.md`, кандидаты в блоки | Собственные формулировки обычно раздуты. Каждый сильный глагол — цель для калибровки |
| Мастер-профиль docx | Всё сразу | Сверка с manifest, поиск неоформленного | Может дублировать существующие блоки. Сверять по manifest, а не по памяти |
| Рекомендательное письмо | Подтверждение масштаба третьей стороной | Усиление секции «Результат» | Указать автора и отношение к проекту |

## Порядок при пачке документов

Резюме первым — оно даёт скелет дат и ролей. Дальше перформанс-ревью и рабочие логи — там метрики. Потом проекты и переписка — там фактура. Конфликт между документами не разрешать самому: показать обе версии и спросить.

## Дедупликация — до всего остального

Прочитать `manifest.md` целиком. Для каждого куска опыта из документа найти похожие блоки по тегам и компании.

| Совпадение | Действие |
|---|---|
| Тот же проект, та же метрика | Не создавать. Показать существующий блок, спросить: дополнить или пропустить |
| Тот же проект, другая грань (новая метрика, другая методология) | Предложить дополнить существующий блок секцией |
| Та же компания, другой проект | Новый блок |
| Сомнительно | Спросить. Не решать самому |

Дубль хуже отсутствия: resume-tailor подтянет оба, и в резюме будет два буллета об одном и том же.

## Извлечение docx

```
python3 -c "
import docx, sys
d = docx.Document(sys.argv[1])
print('\n'.join(p.text for p in d.paragraphs if p.text.strip()))
" <файл.docx>
```

Venv изолированный, доустанавливать ничего не нужно.

PDF: пробовать текстовый слой. Скан без текста не разбирать — сказать прямо и попросить текст.
