# Транскрипты

## Где лежат

| Что | Путь |
|---|---|
| Реальное интервью с компанией | `output/{company}-{role}/interviews/YYYY-MM-DD-{этап}.md` |
| Тренировочный голосовой ответ | `drill/artifacts/YYYY-MM-DD-{трек}.md` |

Этап: `screening`, `hiring-manager`, `tech`, `final`. Реальное интервью ложится в папку отклика — рядом с `posting.md` и `interview-prep.md`, чтобы вся история компании была в одном месте.

## Формат файла

```
---
Компания: <название> | Роль: <роль> | Этап: final | YYYY-MM-DD | 55 мин | EN
Вопросы: <темы вопросов через запятую>
Поплыл: <где ответ рассыпался>
Термины: <незнакомые термины>
Пробелы опыта: <темы без опыта>
Разобрано: YYYY-MM-DD
---

СЫРОЙ ТРАНСКРИПТ — не редактировать

[всё как было записано]
```

Шапку пишет дрилл при разборе. До разбора файл состоит из одного тела.

## Правило чтения

Часовое интервью — 8-12 тысяч слов, около 15 тысяч токенов. Целиком читать только при первом разборе.

| Ситуация | Что читать |
|---|---|
| Первый разбор (шапки нет) | Тело целиком |
| Повторное обращение | Только шапку между `---` |
| Разбор конкретного вопроса | Шапку плюс нужный фрагмент тела через grep по ключевому слову |

Тот же принцип, что `manifest.md` против `blocks/`: сводка дешёвая, тело дорогое.

## Что искать в теле

| Сигнал | Как выглядит в транскрипте |
|---|---|
| Ответ рассыпался | «эээ», «ну как бы», обрыв мысли, переход на другую тему без завершения |
| Уход от вопроса | Ответ не на тот вопрос, который задали. Сверять с формулировкой интервьюера |
| Нет опоры на кейс | Общие слова там, где нужен конкретный проект с цифрой. Признак пробела в базе, а не в знаниях |
| Термин незнаком | Переспрос, «в смысле?», ответ через синоним вместо самого термина |
| Сработало | Вопрос интервьюера углубляется вместо смены темы — значит ответ зацепил |

## No-edit

Транскрипт не редактируется никогда — ни пользователем, ни дриллом. Причёсанный текст скрывает речевые сбои, ради которых запись и делается. Шапка добавляется сверху, тело остаётся как записано.

## Как получить транскрипт

Локально, запись никуда не уходит. `mlx_whisper` и `ffmpeg` уже установлены.

```
python3 scripts/transcribe.py запись.m4a \
  --company altenar-business-analyst --stage final
```

Для дрилла: `--drill voice` вместо `--company` и `--stage`.

Скрипт сам кладёт файл по правильному пути, дописывает строку no-edit и печатает готовую команду разбора. Первый запуск скачивает модель large-v3-turbo, около 1.5 ГБ, дальше работает офлайн. Язык определяется сам, при желании форсируется через `--lang ru` или `--lang en`.
