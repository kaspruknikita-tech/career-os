# Рынок: откуда берутся кейсы

Читать перед `/drill seeds`, перед первым наполнением `drill/market/field/` в `/career-role` и когда банк семян пуст.

Кейс из головы Claude звучит гладко и ничему не учит: в нём нет странных ограничений и неудобных фактов, из которых состоит настоящая работа. Поэтому ситуации берутся из постов людей твоей профессии. Ничего не зашито под профессию: источники ищутся заново под `role.md`.

Файлы: `drill/market/field/` — `sources.md` (откуда), `vocab.txt` (словарь роли), `seeds.md` (банк), `raw/` (сырьё, Claude его не читает), `seen.json`. Скрипт — `scripts/field.py` в папке базы, только стандартная библиотека Python.

Ниже `<field>` = `<база>/drill/market/field`, `<py>` = `python3 <база>/scripts/field.py`.

## 1. Найти источники

Типы мест, а не адреса: адреса находятся поиском под роль и проверяются.

| Место | Что ценного | Как найти | Тип |
|---|---|---|---|
| Сабреддиты профессии | ситуации от первого лица, «что бы вы сделали» | `<py> find-reddit <префиксы>`; `site:reddit.com <роль>` | `reddit` |
| Stack Exchange | вопросы практиков с голосами | `<py> find-se <слова>` | `stackexchange` |
| Публичные Telegram-каналы | практика на языке рынка, разборы, кейсы | `подборка телеграм каналов <профессия>`, `awesome <профессия> telegram` | `telegram` |
| Hacker News | технические роли: разборы, Ask HN | запрос: `postmortem`, `on-call`, `hiring` | `hn` |
| Блоги и хабы через RSS | разборы и статьи практиков | хабы Хабра, теги dev.to и Medium, блоги компаний | `rss` |
| Медиа без ленты по теме (vc.ru, Т—Ж, Substack) | истории «как мы…», провалы | `site:vc.ru <профессия> кейс`, `site:<домен> <профессия> ошибки` | `поиск` |

Нужно: 2–5 сабреддитов, 0–3 сайта Stack Exchange, 3–8 Telegram-каналов, 2–5 лент. Искать на языке рынка и по-английски.

Отсеять сразу: каналы вакансий, новостные ленты без разборов, агрегаторы ссылок, сабреддиты-тёзки по префиксу. Записать в `sources.md` и проверить:

```bash
<py> check <field>
```

«Нет пригодных постов» — статус «выбыл» с причиной. Живых источников меньше трёх — честно сказать, что рынок роли в открытом доступе бедный, и опереться на `banks.md` и `/drill debrief`. Не набивать случайными каналами ради числа.

Словарь `vocab.txt` — 30–80 основ слов роли на двух языках, по одной на строку: `инцидент`, `эскалац`, `churn`, `deploy`. Берётся из «Словаря роли» в `role.md` и типичных ситуаций. Слишком общие слова («работа», «проект», «user») тянут шум.

## 2. Собрать и выжать

```bash
<py> harvest <field> --days 90     # первый раз
<py> harvest <field> --days 14     # дальше, раз в одну-две недели
<py> digest <field> --top 25
```

Сбор идёт 1–3 минуты, сырьё ложится в `raw/<дата>.json`. **Сырой JSON не открывать:** файлы по 100–300 КБ, выжимка делает то же за малую долю токенов. Выжимка берёт сырьё новее строки «Последнее обновление банка», отсекает вакансии и рекламу, оставляет посты со словами из словаря, сортирует по совпадению и отклику, не больше трети из одного источника.

Сбор можно повесить на расписание — `cron` или `launchd`, раз в неделю. Предложить один раз, не настаивать.

## 3. Отобрать семена

Из выжимки — 3–8 семян за раз. Семя — не пост, а то, что из него взято:

| Тип | Что записать | Куда идёт |
|---|---|---|
| ситуация | механика своими словами, факты-якоря (цифры, сроки, ограничения), развилка | главный трек и финальный блок |
| вопрос | что спрашивают и почему это трудно | треки на знание, `interview-prep` |
| спор | две позиции и на чём стоят | защита решения, темы спринтов |
| совет | что практики советуют читать, сколько раз встретилось | кандидат в «Темы спринтов» `role.md` — сначала найти первоисточник |

Правила:

- **Ситуация годится,** если в ней есть ставка, ограничение и развилка. Мнение, анонс, «10 советов», резюме и вакансия — не ситуация.
- **Своими словами.** Текст поста не копировать. Автор, ник и детали, по которым узнаётся человек, не записываются, только ссылка.
- **Разнообразие.** Не больше трети банка из одного источника.
- **Семя — сценарий, не доказательство.** Пост одного человека не подтверждает, что «так делают все».

Записать в `seeds.md` со следующим ID, «Использован» = `—`. Обновить «Последнее обновление банка» датой самого свежего разобранного файла сырья. Строка в `log.md` не пишется: это не сессия.

## 4. Из семени — кейс

Механика та же, **домен и цифры — другие**: отрасль из «Доменов для подмены» в `role.md`, ни одного домена из `core.md`. Иначе человек узнаёт историю и вспоминает ответ, а не решает задачу.

Кейс конкретный: роли, цифры, срок, что решено до него. Под кейсом — перечень заданных фактов (`SKILL.md`, «Пре-флайт»). Проверка перед выдачей: могу ли я сам ответить, зная только то, что написано в условии.

После сессии — в `seeds.md` в колонку «Использован» дату и ID кейса, в строке `log.md` поле `источник:` = ID семени.

## 5. Отдача источников

После каждого отбора:

```bash
<py> yield <field>
```

Источник без семян после трёх разобранных сборов — «кандидат на удаление». Одной строкой предложить заменить его новым, менять статус после «да».

## Ограничения

- Только публичные страницы, без входа в аккаунт. Закрытые чаты и Discord сборщик не читает — истории оттуда человек приносит сам, в банк они идут без имён.
- Reddit читается через публичный архив arctic-shift; архив недоступен — ошибка по этому источнику, остальные собираются. Запасной путь — поиск `site:reddit.com`.
- Stack Exchange без ключа — около 300 запросов в день, хватает с запасом.
